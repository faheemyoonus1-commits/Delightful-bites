# Delightful Bites (Class 4 English, Unit 4)

Interactive lessons with Malayalam support. Created by Faheem Yoonus V K, ALPS Cherukulathur East.

- `index.html` lessons: Stone Soup, Runaway Pancake, poem, word meanings, quizzes
- `practice.html` extra quiz and word scramble
- `generate_audio.ps1` makes the recorded narration (needs an ElevenLabs API key; never upload the key)

Live site: https://faheemyoonus1-commits.github.io/Delightful-bites/
